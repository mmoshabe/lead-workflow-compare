# The workflow every platform implements

The same steps, inputs and outputs on n8n, Make and Zapier, so the comparison is about the platforms rather than three different designs.

## 1. Trigger: a lead arrives (webhook, POST JSON)

```json
{
  "lead_id": "t07",
  "name": "Thabo Nkosi",
  "email": "thabo@example.co.za",
  "company": "Example Logistics",
  "phone": "082 000 0000",
  "project_type": "Integration / automation",
  "budget": "R100k to R250k",
  "timeline": "Next quarter",
  "message": "Our Sage ERP and Shopify store don't talk to each other...",
  "source": "website"
}
```

`lead_id` is set by whoever sends the lead (the test harness uses the case ID) and is carried through to every output, so results can be matched.

## 2. Qualify: one Claude call (identical on every platform)

- Model `claude-haiku-5-5`, `output_config.effort: low`, structured output with [`prompt/schema.json`](prompt/schema.json).
- System prompt: [`prompt/qualify.md`](prompt/qualify.md), followed by `<business_facts>` with [`business/11oclock.md`](business/11oclock.md).
- User message: the lead as tagged text, built exactly as in [`prompt/request.template.json`](prompt/request.template.json), which is generated by `scripts/build_request.py`.
- Called as a raw HTTP request on every platform, so the prompt and model are byte-identical. (Native "Claude" modules are compared separately in the write-up.)

## 3. CRM: append one row to the Google Sheet

Spreadsheet "11OCLOCK leads: platform comparison", one tab per platform (`n8n`, `make`, `zapier`), with columns A to P:

| A | B | C | D | E | F | G | H | I | J | K | L | M | N | O | P |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| Received | Lead ID | Name | Email | Company | Fit | Service | Budget band | Urgency | Next step | Summary | Missing info | Red flags | Follow-up subject | Follow-up draft | Input tokens / Output tokens |

## 4. Alert: Slack message to the team channel

Only for `call` and `email`, so the partners aren't pinged for spam. Each message starts with the platform's name, since all three post to the same channel during the comparison:

> [n8n] **New lead (high fit, call)**: Thabo Nkosi, Example Logistics. Sage ERP and Shopify integration, R100k to R250k, next quarter.
> Draft reply is in the leads sheet (row for t07).

## 5. Nothing is ever sent to the lead automatically

The follow-up is a draft in the Sheet. A partner reviews it and sends it.
